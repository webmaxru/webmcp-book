# Design Sources

This package was synthesized from the following public projects and ideas:

- AshwinSathian/humanize-writing-skill
  - structural shape over word lists
  - voice and genre scoping
  - false-positive awareness
- isatimur/de-slop
  - fidelity over flair
  - hollow vs. rewordable triage
  - removal test
  - idempotence
  - report rather than silently invent
- soodoku/on-writing
  - macro-to-micro editing
  - argument before sentence polish
  - human-draft protection
  - voice calibration
- anildash/better-documents
  - audience and purpose
  - reader-first sequencing
  - buried-ask detection
  - formatting restraint
- rohitjz/clear-writing-for-pms
  - reader / one-point / minimum-evidence framing
  - concrete professional writing
  - objective + qualitative eval split

This implementation deliberately does not inherit blanket punctuation bans,
blanket vocabulary bans, or mandatory word-count reduction targets.

Those can be useful house-style choices, but they are not reliable universal
editing rules and can conflict with voice preservation.
